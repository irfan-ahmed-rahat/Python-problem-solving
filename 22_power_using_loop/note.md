(যেমন: বেইজ ২ এবং পাওয়ার ৩ হলে, 2^3 = 2 *2 *2 = 8)

"""
Problem 22: Calculate power using loop (e.g., 2^3 = 8).
"""

# ধাপ ১: ইউজারের কাছ থেকে বেইজ (Base) এবং পাওয়ার (Power) ইনপুট নেওয়া
base = int(input("Enter your base number: "))
power = int(input("Enter your power number: "))

# ধাপ ২: গুণফল জমানো (গুণের ক্ষেত্রে মান 1 হয়)
result = 1

# ধাপ ৩: লুপটি ঠিক 'power' সংখ্যক বার ঘোরানো
for i in range(1, power + 1):
    
    # ধাপ ৪: ব্যাংকের জমানো মানের সাথে প্রতিবার বেইজ (base) গুণ করা
    result = result * base

# ধাপ ৫: লুপের বাইরে এসে ফাইনাল ফলাফল প্রিন্ট করা
print(f"{base} to the power of {power} is: {result}")

########################################################################



শুরুর প্রস্তুতি (লুপের আগে)

  Base = 2 (যাকে গুণ করব)
 
  power = 3 (যতবার গুণ করব)
 
 result = 1 (শুরুতে এর মান ১)
 
লুপের রেঞ্জ দেওয়া হয়েছে range(1, power + 1) অর্থাৎ range(1, 4)। তার মানে লুপটি ১, ২ এবং ৩ এর জন্য মোট ৩ বার ঘুরবে।

লুপের ১ম চক্কর (i = 1)

লুপের ভেতরে ঢুকল। আমাদের কাজ হলো  বর্তমান মানের সাথে বেইজকে গুণ করা:

হিসাব: result = result * Base

মান বসাই: result = 1 * 2

 নতুন মান: এখন result জমা হলো 2।
 
লুপের ২য় চক্কর (i = 2)

আবার লুপের ভেতরে ঢুকল।

  হিসাব: result = result * Base
  
  মান বসাই: result = 2 * 2 (কারণ  আগে থেকেই ২ জমা ছিল, আর বেইজ তো ২-ই আছে)
  
  নতুন মান: এখন ব্যাংকে জমা হলো 4।
  
লুপের ৩য় এবং শেষ চক্কর (i = 3)

লুপ শেষবারের মতো ভেতরে ঢুকল।

  হিসাব: result = result * Base
  
  মান বসাই: result = 4 * 2 (ব্যাংকের জমানো ৪ এর সাথে বেইজ ২ গুণ)
  
   নতুন মান: এখন result e জমা হলো 8।
লুপ শেষ এবং প্রিন্ট
যেহেতু রেঞ্জ range(1, 4) ছিল, তাই ৩ বার ঘোরার পর লুপটি থেমে যাবে।
লুপ থেকে বেরিয়ে সে প্রিন্ট ফাংশন পাবে এবং সেখানে ব্যাংকের ফাইনাল জমানো মান অর্থাৎ 8 স্ক্রিনে প্রিন্ট করে দেখাবে!
