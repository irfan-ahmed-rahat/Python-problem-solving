
প্রবলেম ১৯: ফিবোনাচি (Fibonacci) সিরিজ প্রিন্ট করো n তম পদ পর্যন্ত ফিবোনাচি সিরিজ কী?

এটি হলো সংখ্যার এমন একটি ধারা, যেখানে প্রতিটি নতুন সংখ্যা তার আগের দুটি সংখ্যার যোগফল হয়ে তৈরি হয়।

ধারাটি শুরু হয় 0 এবং 1 দিয়ে।

০ + ১ = ১
১ + ১ = ২
১ + ২ = ৩
২ + ৩ = ৫
৩ + ৫ = ৮
অর্থাৎ সিরিজটি দেখতে এমন হয়: 0, 1, 1, 2, 3, 5, 8, 13, 21...


কেন দরকার? (Real-Life Application)

স্টক মার্কেট বা ক্রিপ্টোকারেন্সির টেকনিক্যাল অ্যানালাইসিসে (Fibonacci Retracement) এই ধারার ব্যাপক ব্যবহার রয়েছে। 
এছাড়া প্রকৃতিতে গাছের পাতার বিন্যাস, শামুকের খোলস বা সূর্যমুখীর বীজের প্যাটার্ন সবখানেই এই ফিবোনাচি লজিক লুকিয়ে আছে!





"""
Problem 19: Print the Fibonacci series up to n terms.
"""

#ধাপ ১: ইউজারের কাছ থেকে ইনপুট 
n = int(input("Enter how many terms you want: "))

#ধাপ ২: ফিবোনাচির শুরুর দুটি ফিক্সড সংখ্যা
num1 = 0
num2 = 1

print(f"\nFibonacci Series up to {n} terms:")

#ধাপ ৩: লুপ 
for i in range(1, n + 1): # range(num) দিলেও হবে

    #মানে হচ্ছে লুপ টা কতবার ঘুরবে range ( num ) , তাহলে ইউজার যদি 5 ইনপুট দেয় তাহলে ৫ বার ঘুরব

    #ধাপ ৪: প্রথম সংখ্যাটি প্রিন্ট  
    print(num1, end=" ")
    
    #ধাপ ৫: আগের দুটি সংখ্যা যোগ করে নতুন সংখ্যা তৈরি 
    next_num = num1 + num2
    
    #ধাপ ৬: মানগুলো এক ঘর করে সামনে এগিয়ে 
    num1 = num2
    num2 = next_num


print(num1, end=" ") 

নোট: end=" " দিলে সংখ্যাগুলো নিচে নিচে প্রিন্ট না হয়ে পাশাপাশি স্পেস দিয়ে প্রিন্ট হয়)।

ধরি, ইউজার n = 3 দিয়েছে
লুপের ১ম চক্কর:
প্রিন্ট করল: 0 (কারণ num1 এর মান 0)
নতুন সংখ্যা: next_num = 0 + 1 (মান হলো 1)
চেয়ার বদল: num1 হয়ে গেল 1, এবং num2 হয়ে গেল 1।

লুপের ২য় চক্কর:
প্রিন্ট করল: 1 (কারণ num1 এর মান এখন 1)
নতুন সংখ্যা: next_num = 1 + 1 (মান হলো 2)
চেয়ার বদল: num1 হয়ে গেল 1, এবং num2 হয়ে গেল 2।

লুপের ৩য় চক্কর:
প্রিন্ট করল: 1 (কারণ num1 এর মান এখন 1)
নতুন সংখ্যা: next_num = 1 + 2 (মান হলো 3)
চেয়ার বদল: num1 হয়ে গেল 2, এবং num2 হয়ে গেল 3।
লুপ ৩ বার ঘুরে শেষ! আমাদের স্ক্রিনে প্রিন্ট হলো: 0 1 1
